## 显示与行为

- 仅在明确错误类型时显示具体原因，不把未知写入故障判断成权限问题。
- 原始英文错误留作排查，不直接渲染到用户正文；本次不新增日志查看入口。
- 当前失败状态使用原有文案位置与按钮，长文案换行并增加行高，不缩小字号、不压住按钮。
- “结果已保留”“无需重新转写”只在确认可复用结果存在时显示；无此证据则省略。
- 重试沿用已有任务参数及防重规则；中断任务仍是手动继续，未准备模型仍须先准备模型。
- 不改重试流程，不改录音或模型文件，不清理既有数据。
