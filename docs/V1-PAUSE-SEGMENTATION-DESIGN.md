## 实现约定

- 秒数为可编辑数值，初始默认6。输入须是大于0的有效数值；空值、零、负数或无效输入在原参数区提示，不计算。
- 编辑数值不自动重算；点击“重新预览”后计算。结果标注它实际使用的秒数，避免新输入与旧结果混淆。
- 计算中沿用同一区域显示“正在预览”，禁止重复提交；失败显示原因和重试，保留旧结果及其参数标签。没有满足阈值的内部停顿时，预览整条录音为一段。
- 全部音频时间及转写文字保留；不按话题切分、不增加文本模型。停顿中点分界与跨界文字暂归属规则见6秒验证文档，不宣称字词级精确对齐。
- 本稿覆盖参数及预览，不增加批量提取或隐式覆盖已提取内容。分段持久化、与主列表接线及提取操作需在对应实现批次明确。
