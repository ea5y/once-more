# Once More V1 产品范围

更新：2026-09-22。本文归档本轮会议中用户明确确认的结论，取代本文件此前与之冲突的内容；优先于早期 Echo 方案、开发中的暂定安排及旧设计稿。

**文档状态：产品范围已确认；UI 确认稿待用户审阅。本文描述目标范围，不代表功能已实现或已获编码授权。**

## 1. 产品核心

每一段对话都是记忆。V1 将录音中的全部对话划分为可回听、可独立提取的片段（Memory），不筛选所谓有价值的内容，不做重要性排名或推荐。

自动处理负责转写与对话分段。分类、细分不决定一段对话是否保留；本轮未将额外的分类管理功能列入 V1。

当前只交付 Mac 桌面应用，Windows 暂不安排。

## 2. 录音来源与处理流程

- 使用现有配置中的录音来源文件夹，记住用户的选择。
- 用户点击“扫描新录音”后，查找新增录音，自动完成压缩、上传、转写与对话分段。
- 已处理的录音不重复处理，不要求用户逐份点击开始。
- 结果进入“全部”；处理期间显示进度，已有记忆仍可浏览和回听。
- 不做后台自动监听。

## 3. 对话分段规则

- 按一次相对完整的交谈分段，不限定片段时长。
- 交谈中换话题不自动拆分。
- 短暂停顿、简短回应以及交谈中的笑声保留在同一段中。
- 明显结束后重新开始的交谈，划为另一段。
- 片段首尾保留少量余量，避免截掉人声开头或尾音。
- 停顿阈值、首尾余量等具体参数通过实际录音验证后确定。
- V1 不单独识别或分类环境声、笑声；这不意味着删除对话中夹带的这些声音。

## 4. 标题、转写与播放

- 片段标题直接取第一句话，不由 AI 另行概括；列表中长标题截断显示。
- 详情显示完整对话文字，不区分或标注说话人，也不识别真实姓名。
- 显示片段时间与时长，便于按时间浏览。
- 点击转写中的一句话，从该句对应音频位置开始，连续播放到片段结束。
- 当前播放句突出显示；正文自动滚动，使当前句保持可见。
- 用户手动滚动正文后暂停自动跟随，提供“回到当前句”入口。
- 搜索匹配与当前播放句使用不同高亮；搜索本身不触发播放。
- 列表标题单行省略，鼠标停留可查看完整第一句话；详情标题最多两行，可展开完整内容。
- 长转写仅在正文区域内滚动；播放器及底部操作保持可见。搜索定位与播放跟随不带动整个页面滚动。
- 不提供手动修改标题、转写或说话人的功能。

## 5. 导航、收藏与搜索

### 导航与收藏

- 两个 Tab：**全部、收藏**。
- “全部”展示所有对话记忆；“收藏”展示用户主动收藏的记忆。
- 心形按钮使用“收藏 / 已收藏”，再次点击取消收藏。
- 收藏仅是标记，与提取音频独立；未收藏的片段同样可以回听和提取。
- “再听一次”保留为产品概念，不设独立 Tab。
- 收藏列表复用全部列表样式、时间顺序与详情，仅显示已收藏片段。
- 在收藏列表取消收藏后，该项从列表移除，记忆和音频不被删除。
- 若取消的是正在查看或播放的片段，保留当前详情与播放，直到用户选择另一段或切换页面；提示“已取消收藏”，提供“撤销”。

### 全局搜索

- 搜索所有片段的完整转写，不限于标题或当前日期；从收藏页发起也搜索全部记忆。
- 自动选中第一条匹配片段，在详情中定位匹配文字；不自动播放。
- 其他匹配片段仍可供用户选择。

### 片段内搜索

- 只搜索当前详情中的转写。
- 定位并突出显示匹配文字，不切换片段，不自动播放。
- 用户点击句子后才开始播放。

## 6. 手动调整边界

是否允许调整，取决于原始音频是否存在，而非片段是否已提取。

| 情况 | 起点、终点调整 |
|---|---|
| 原始音频存在，尚未提取 | 允许 |
| 提取确认流程中，原始音频存在 | 允许，并可试听 |
| 已提取，原始音频仍存在 | 允许 |
| 已提取，原始音频不存在 | 不允许 |

- 只调整起点和终点，不做手动拆分、合并。
- 调整片段范围不修改原始录音。
- 正文随范围更新：缩小范围移除范围外文字，扩大范围补入对应转写。
- 标题自动更新为调整后片段的第一句话，收藏状态不变。
- 允许边界落在一句话中间，不强制吸附句子边界；被截断部分的文字显示规则需结合转写时间精度验证，尚未最终确定。
- 已提取的片段修改边界后，标记为“需要重新提取”。
- 必须按最新边界重新提取完成，才重新满足该片段的提取完成条件。

## 7. 片段提取与保存

- 仅支持逐段提取，不做批量提取。
- 提取流程允许确认范围、调整起点终点并试听。
- 从本地原始音频提取，优先保留音质；不使用上传云端的压缩副本作为最终片段来源。
- 保存至现有配置中的输出文件夹，不增加另一套保存位置配置，不要求每次选择目录。
- 文件名采用“录音日期＋片段开始时间＋第一句话”；示例：2026-09-10_21-16-00_我还挺想以后去海边住一阵子的.wav（扩展名只作示例）。
- 标题过长时缩短文件名，去除文件名不支持的字符；应用内完整标题不变。重名自动加序号，不覆盖已有文件。
- “查看文件”在 Finder 中打开所在文件夹并选中该文件。
- 重新提取成功后，应用使用新文件；旧文件保留，不自动删除。
- 具体音频格式、编码参数尚未确定，不将讨论中的示例格式视为已确认标准。

## 8. 云端处理与副本生命周期

确定采用：**原音频留在本地，生成压缩副本上传云端，结果保存在本地。回听与最终提取使用本地原音频。**

- 压缩保留完整时间轴，不删除静音、不改变播放速度，以便云端返回的句子时间对应原录音。
- 具体压缩格式、码率及时间定位准确性需用实际录音验证；Opus 32 kbps 仅是此前提出的测试起点，并非固定规格。
- 本轮明确纠正：“副本”指本地压缩生成、用于上传解析的音频文件，不是云端存储文件。
- 转写成功且结果成功保存到本地后，删除本地压缩副本。
- 转写失败时保留本地压缩副本，手动重试时复用，不必重新压缩；是否重新上传由接口方案决定。
- 云端是否存储音频、如何提交解析、如何恢复任务尚未确定；不预设云端副本管理或清理失败流程。服务商自身的数据保留政策需在选型时核实。
- 本地压缩副本与原始录音分别管理：删除压缩副本不会改变原始录音的删除条件。
- 云端服务商、模型尚未最终选定。文档与设计工作不构成上传个人录音或付费调用的执行授权。

## 9. 失败与重试

- 用户可见阶段先使用通用表述：准备音频 → 正在识别（含等待处理）→ 正在整理对话 → 完成（显示对话片段数量）。
- 有真实进度时才显示百分比，否则仅显示阶段，不编造剩余时间。
- 保留失败任务，显示失败阶段与原因，支持手动重试；是否重新上传及从哪个阶段恢复，待接口方案确定。
- 原型不包含云端副本管理和云端清理失败界面。
- 不做后台自动重试；“继续尝试”按手动重试处理。
- 成功结果保存在本地，重新打开应用仍可查看。
- 处理未完成时，不允许通过应用删除原录音。

## 10. 删除原录音

### 删除条件

- 某份原录音的全部对话片段均已按最新边界提取完成，包含未收藏片段。
- 独立音频应实际存在、可解码且时长完整，不能仅依赖数据库成功标记。
- 存在未提取、需要重新提取或尚未处理完成的片段时，不满足删除条件。
- 零片段不能自动视为可删除原录音。

### 删除操作

- 用户主动发起并确认，将原录音移到系统废纸篓，不直接永久删除。
- 删除流程在显示“已移到废纸篓”时结束，不要求用户回听片段作为删除步骤。以后仍可正常回听已提取片段。
- 确认界面说明：未进入片段的声音不会保存在提取文件中；原录音不存在后不能继续调整边界。

### 删除后保留的能力与信息

- 独立片段音频仍可回听、导出。
- 完整转写仍可全局搜索、片段内搜索，点击句子仍可定位播放。
- 保留第一句话标题、录音时间、收藏状态、原录音名称等来源信息。
- 标注原录音已删除，播放转为使用独立片段音频。
- 起点、终点不可再调整。

## 11. 明确不做的内容

- 记忆价值筛选、推荐、重要性排名。
- 环境声或笑声的单独识别、分类。
- 照片。
- 修改转写、说话人或 AI 标题；标题直接使用第一句话。
- 手动拆分、合并片段。
- 批量提取。
- 后台自动监听录音文件夹、后台自动重试。
- 当前阶段的 Windows 交付。

## 12. 尚待验证或决定

- 云端服务商与模型、服务商数据保留政策。
- 上传副本的编码格式与压缩参数，以及对轻声、远处人声等内容的识别影响。
- 对话结束阈值、片段首尾余量。
- 句子时间定位与原音频、独立片段之间的准确对应；边界落在句中时的文字呈现方式。
- 最终提取音频的具体格式和编码参数，原则为优先音质。

以上事项不能被设计示例或临时实现默认为已确认。

## 13. 协作与执行规则

### 会议与执行授权

1. 讨论期间只讨论，不擅自修改文件、代码或设计稿。
2. 用户明确说“会议结束”后，才进入执行确认阶段。
3. 执行前说明具体操作范围，询问用户，取得明确同意后才执行。
4. “没错”“可以”“建议采纳”等讨论中的认可，仅确认讨论结论，不自动视为执行授权。
5. 已授权范围内可以继续推进；新增范围需另行确认。用户明确要求的只读查看与分析，按该请求范围进行。

### UI 设计先行

1. 先讨论范围，再落地 UI 设计稿，覆盖相关页面、操作流程与必要状态。
2. 用户确认设计稿及改动范围后，才能申请并进入对应编码工作。
3. 编码以确认稿为依据；新增或改变界面，先回到设计稿讨论、确认。
4. 制作和修改设计稿也属于执行，需要相应授权。
5. 交付时按设计稿与实现逐项核对，便于用户知道改了什么。

### 额度与暂停

- 用户要求关注额度，不足时提前停止，说明已完成与剩余工作。
- 多个额度窗口同时生效，不能仅以当前时段剩余量判断可用额度。
- 用户本次曾明确允许在周额度偏低时继续制作设计稿，不据此推定以后可无视额度提醒。

## 16. 2026-09-21 可点击原型范围

1. 查找与回听：全局搜索 → 自动选中首条 → 点击句子播放。
2. 调整与提取：调整起止点 → 试听 → 提取 → 查看文件。
3. 删除原录音：查看关联片段 → 检查提取状态 → 确认移到废纸篓 → 删除完成。

原型的播放、处理进度及 Finder 展示均用模拟状态表达，不接真实音频、真实云端，不执行真实文件删除。失败与空状态保留为独立稿件供检查。制作完成后由用户审阅，不据此认定 UI 已获最终确认或应用功能已完成。
