## 五、设计稿与规则缺口

2026-09-21 已讨论并确认以下规则，用户授权落稿及连接原型。代码状态不因设计更新而改变。设计完成与验证记录见末尾。

| 编号 | 项目 | 已确认规则 / 待验证事项 |
|---|---|---|
| D01 | 句子播放 | 从点击句连续播至片段结束；当前句高亮并跟随；手动滚动暂停跟随，提供回到当前句；搜索高亮不同色且不自动播放 |
| D02 | 边界调整后的正文与标题 | 正文随范围更新，标题取调整后第一句话，收藏不变；允许句中边界，截断文字显示待时间精度验证 |
| D03 | 长对话 | 列表单行省略、悬停完整标题；详情两行可展开；正文独立滚动，播放器和底部操作保持可见 |
| D04 | 收藏列表 | 复用全部样式；取消收藏移除列表项，保留正在查看/播放的详情直到另选或切页，提供撤销；全局搜索不受收藏限制 |
| D05 | 文件保存 | 日期＋片段开始时间＋第一句话，长标题缩短、非法字符清理、重名加序号；应用内完整标题不变 |
| D06 | 提取结果 | 查看文件在 Finder 中选中文件；重新提取使用新文件，保留旧文件 |
| D07 | 任务阶段 | 准备音频、识别、整理对话、完成；真实进度才显示百分比；失败手动重试；复用本地压缩副本，不预设云端存储及恢复方式 |
| D08 | 原型关系 | 三条流程：查找回听、调整提取查看文件、删除至完成；删除不要求回听；模拟音频与进度，不执行真实操作 |

范围文档另列的技术待定项继续保留：云端服务商与模型、服务商数据保留政策、压缩与提取参数、分段阈值、音频时间定位验证。不得以示例参数替代最终决定。
