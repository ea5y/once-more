# 日期时间轴实现记录 · 2026-11-06

依据：Penpot 03·主界面（有内容）48 草稿，用户已同意编码。

## 已实现

- 抽离 `src/v1/DateRail.tsx`，主界面使用同一组件。
- 细线固定贯穿可视区域，日期少时也不缩短；滚动区域与细线分离。
- 日期采用 MM.DD、圆点和选中圆环，固定 88px 节点间距；跨年处显示年份。
- 日期区域独立滚动，不监听滚动事件切换日期；点击沿用原有日期切换逻辑。
- 日期集合由当前全部／收藏及搜索结果提供；外部选中日期改变时，仅在日期区域内将选中项滚入可见范围。
- 保持现有主界面宽度与详情、播放状态规则。
